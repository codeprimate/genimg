# Release v0.18.0 - 2026-10-24

## Overview

You can set the output frame with an aspect ratio and a maximum extent. The same pair works on the CLI, in the Python library, and in the web UI. The saved image matches that request.

## New Features

- **Output size**: `genimg generate` and `genimg character` take `--aspect-ratio` and `--max-extent`. Pass both flags, or neither. `--aspect-ratio` is `auto` or a ratio such as `16:9`. `--max-extent` is the longer side in pixels, from 1024 through 2048.
- **Library**: `generate_image()` takes `aspect_ratio` and `max_extent`.
- **Web UI**: An Output size block sits under the provider and model row. Leave both controls at the model default, or set them together. Wiro models show schema ratio labels when the schema has an aspect list.

## Improvements

- **Wiro**: A set pair maps to the model schema. Ratio models send the closest aspect option and a resolution tier when the schema has one. Pixel models send width and height. An omitted pair copies the schema `defaultvalue`. It does not force `aspectRatio` to `1:1` or a reference size of `1024`.
- **Draw Things**: A set pair replaces the canvas for that run and snaps each side to a multiple of 64. `GENIMG_DRAW_THINGS_WIDTH_PX` and `GENIMG_DRAW_THINGS_HEIGHT_PX` apply only when the pair is omitted.
- **OpenRouter and Ollama**: These providers still send no size field. The saved image is fitted to the request after the provider returns.
- **Saved image**: `auto` scales the long side. Any other ratio is center-cropped, then scaled so the long side equals the requested extent.

## Breaking Changes

- **Omitted Wiro size**: A run that does not set the pair now uses the model schema default. It no longer forces a square `1:1` frame or a `1024` reference canvas.
  - *Migration*: Pass `--aspect-ratio` and `--max-extent` together when the frame must stay fixed. Example: `--aspect-ratio 1:1 --max-extent 1024`.
  - *Affected*: Wiro text-to-image runs and Wiro runs that send a reference image.

## Documentation

- README and the changelog describe the flags, the extent bounds, and the per-provider mapping.

## Upgrade Instructions

1. Upgrade the package: `pip install -U git+https://github.com/codeprimate/genimg.git` (or `pip install -e .` from a fresh clone).
2. To request a frame, set both size controls. Omit both to keep the model default.
3. Reference image padding still uses `Config.aspect_ratio`. That setting is separate from the output-size pair.
