# Release v0.17.0 - 2026-06-27

## Overview

Adds **Wiro.ai** as a cloud image generation provider with schema-aware API integration and reference-image support for models that accept file inputs.

## New Features

- **Wiro provider (`wiro`)**: Generate images via the Wiro marketplace API using `owner/model` slugs (default: `bytedance/seedream-v4-5-uncensored`). Works from CLI (`--provider wiro`), Gradio, and `generate_image()`.
- **Reference images on Wiro**: When a model's Tool/Detail schema includes file inputs, reference images are sent as multipart Run payloads.
- **Model list**: Bundled suggestions include Seedream v4.5, Seedream v5 Lite, Flux, Nano Banana Pro, and Flux.1 Dev variants.

## Improvements

- **`models.yaml`**: Centralized default model IDs (replacing `ui_models.yaml`); env vars still override yaml defaults.

## Bug Fixes

- **Provider credentials**: Wiro no longer receives the OpenRouter API key when `generate_image()` is called without an explicit `api_key`.
- **Seedream and similar models**: Required Run parameters from the Wiro schema (e.g. `maxImages`, `watermark`) are populated automatically.

## Documentation

- README, SPEC, AGENT, DEVELOPMENT, and `.env.example` updated for Wiro configuration and integration tests.

## Upgrade Instructions

1. Upgrade the package: `pip install -U git+https://github.com/codeprimate/genimg.git` (or `pip install -e .` from a fresh clone).
2. For Wiro: set `WIRO_API_KEY` and `WIRO_API_SECRET` (from [wiro.ai panel](https://wiro.ai/panel/project)).
3. Optional: `GENIMG_DEFAULT_IMAGE_PROVIDER=wiro` and `GENIMG_DEFAULT_WIRO_IMAGE_MODEL=bytedance/seedream-v4-5-uncensored`.
4. No breaking changes for existing OpenRouter, Ollama, or Draw Things workflows.
