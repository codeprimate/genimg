# Release v0.19.0 - 2026-11-05

## Overview

`genimg generate` can now talk to scripts. Add `--json` and stdout holds one JSON line instead of prose: the saved path, model, generation id, reported cost, time, and image size. A failure prints the same single line with the error kind and still exits non-zero.

## New Features

- **`genimg generate --json`**: one JSON line on stdout, for scripts. It implies `--quiet`, so progress and the banner stay out of the way. Success keys: `ok`, `path`, `model`, `generation_id`, `cost`, `seconds`, `width`, `height`. Failure keys: `ok` (false), `kind` (the exception class name), `message`, and `status` (the HTTP status when the provider gave one). Exit codes do not change: 1 for API and network errors, 2 for validation and config, 130 for cancellation.
- **Library**: `GenerationResult` carries `generation_id` and `cost` when the provider reports them, and `None` when it does not. OpenRouter reports both today.

## Improvements

- **OpenRouter no-image errors**: The message says why the response held no image. It names the finish reason, the native finish reason, any error, and the text or refusal the model sent (first 500 characters). Previously the message only said that no image was present.

## Documentation

- Added `AGENTS.md`, an agent guide with the test and lint commands, conventions, and constraints. It replaces `AGENT.md`, which had stale paths and stale test instructions.

## Developer Experience

- **One formatter and one linter.** Ruff now does both jobs. The pre-commit hook is `ruff-format` plus `ruff`, `[tool.black]` is gone, and black is out of the dependencies. A single `ruff format` pass reformatted 13 files. The ruff pin and the pre-commit rev are kept in step. See ADR-022.
- **Static checks are clean.** `make lint` goes from 536 errors to zero and `make typecheck` from 398 to zero. Generated FlatBuffers and protobuf stubs under `core/providers/draw_things/generated/` are excluded from ruff, mypy, and coverage, matching the other generated code. The hand-written type errors are fixed with no behavior change. See ADR-023.
- **Test suite is green.** `tests/unit/test_models.py` now expects the bundled optimization default. It had asserted a superseded model ID since before 0.17.0.

## Upgrade Instructions

1. Upgrade the package: `pip install -U git+https://github.com/codeprimate/genimg.git`, or `pip install -e .` from a fresh clone.
2. Nothing to migrate. The two new result fields are optional and default to `None`.
3. Scripts that read the printed path from stdout keep working. Add `--json` when you want the whole result on one line.

## Notes

- `--json` belongs to `generate`. `genimg character` has no such flag and still prints its path line.
- The package is not published to PyPI. Install from GitHub or a local clone.
- **Known:** coverage is 77.3% once generated code is excluded, below the 80% floor enforced by `pyproject.toml` `addopts`. `make test` therefore still exits non-zero on the coverage check alone. The uncovered code sits mostly in the Gradio UI and the local Draw Things client.
